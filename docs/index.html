About this dashboard

  • Data: City of Dallas Open Data — 311 Service Requests (d7e7-envw), every request created since Oct 1, 2024 plus older requests still open, loaded into PostgreSQL.
  • On time: closed at or before the city's "overall service request due date". Duplicates, transfers to other agencies and cancellations are excluded.
  • Mix-adjusted district gap: indirect standardization — each district's observed on-time rate minus the rate it would have if every request type performed at its citywide rate.
  • Method, SQL and code: GitHub repository. Built by Jude (Joochan) Lee · @ratemyguy.
